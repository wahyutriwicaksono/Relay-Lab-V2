# V1 Frozen Baseline — Reconstruction Note

V1 remains a legacy reference and is not overwritten by this V2 package.

The available Project artifact shows the V1 workbench contained:
- Relay Lab Secondary Injection Simulator / Engineering Workbench
- Function library including 51, 50, 51N, 50N, 87T, 67, 27, 59, 59N, 81U, 81O, 46, 32R, 24, 25, 63
- Generic Multifunction and visual/reference profiles for NR PCS-9671S, PCS-985, PCS-974
- Single Shot, Ramp pickup/dropout, State Sequence
- 6I / 6V injection console, phasor, waveform, frequency
- 51 IEC Standard/Very/Extremely Inverse and Definite Time settings
- CT/VT basis, predicted response, event/binary trace, session report, CSV export
- training presets: normal, fault/pickup, 5x pickup, pickup/dropout, BI1 disconnected

Raw Work source code was not exposed by File Library; therefore this V2 package is a faithful source reconstruction and extension of the preserved functional state, not a claim of byte-for-byte source continuity.
